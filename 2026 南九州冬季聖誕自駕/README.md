## 📂 檔案目錄結構

```text
生活小秘書/旅行/
├── README.md               # 模組說明文件
├── sync_from_sheets.py     # 自動從 Google 試算表拉取最新行程與費用並重新編譯
├── build_dashboard.py      # 儀表板 HTML 核心編譯腳本
├── open_dashboard.sh       # 一鍵自動雲端同步並開啟儀表板腳本
├── travel_data_import.xlsx # 自動同步的試算表快取檔
├── index.html              # 高質感單頁互動式旅行儀表板
└── data/
    ├── current_trip.json   # 南九州自駕旅程完整結構資料
    ├── trips_history.json  # 旅程歷史清單
    └── parsed_kyushu_trip.json # 試算表轉換之原始中繼 JSON
```

## 🚀 一鍵啟動與雲端同步

日後若在 Google 試算表新增記帳或修改行程，只要在終端機執行：

```bash
cd "旅行"
./open_dashboard.sh
```

系統將會**自動從 Google 試算表下載最新資料 ➔ 重新編譯 ➔ 在瀏覽器中無縫開啟**！
