# 3D 入口大廳（Travel Portal）冬季南九州島 — 設計文件

- 日期：2026-10-25
- 範圍：根目錄 `index.html` 的 3D 島嶼區塊（由 `build_portal.py` 產生）
- 狀態：待使用者核可

---

## 1. 目的與為什麼

目前首頁 3D 島只是雛形：橢圓形陸塊、螢光綠地表、景點與人物單調、沒有海洋天空與真實陰影，標題還留著「沈伯洋政策島」字樣。
目標是把它升級成**一座照南九州真實輪廓打造的 2.5D 冬季小世界**，讓家人一打開網頁就認出「這是我們 12 月要去的地方、這是我們四個人」，並對行程產生期待。

## 2. 目標 / 非目標 / 反目標

**目標**
1. 陸塊照南九州實際海岸線（low-poly 簡化），景點放在真實地理位置。
2. 紅色小巴沿真實自駕路線（行程順序）繞行，含櫻島渡輪段。
3. 12 月冬季氛圍：低彩度地表、山頂薄雪、低角度暖陽、長陰影、聖誕燈飾、櫻島冒煙、溫泉蒸氣。
4. 海洋、天空、雲、太陽，所有物件真實投影（shadow map）。
5. 4 位角色可一眼辨識，各有專屬動作與依景點變化的台詞。
6. 熱鬧的街景：路人、店家、熊本市電、小貓小狗、渡輪等動畫物件。
7. 標題改為符合行程，移除所有「沈伯洋 / 政策島」字樣（含程式註解與 console 輸出）。
8. 發佈前提供 `preview.html` 讓使用者逐一檢視角色、景點、物件與完整場景，以文字回饋細調。

**非目標**
- 不做寫實地圖或真實比例（2.5D 可愛比例優先）。
- 不改 `2026 南九州冬季聖誕自駕/` 手帳本身。
- 不做預覽頁上的滑桿 / 即時調色工具（使用者選擇用文字回饋）。
- 不改下方旅程卡片區的功能（只改上方 3D 區與標題文字）。

**反目標（技術上能跑但算失敗）**
- 手機（iPhone 直式）卡頓、發燙或載入超過數秒。
- 島嶼形狀看不出是南九州。
- 角色長得一樣、分不出誰是誰。
- 阿嚕被做成熊本熊的仿冒造型（版權風險）。
- 畫面顏色刺眼、高對比霓虹色（違反 AGENTS.md 配色哲學）。

## 3. 限制條件

- Three.js r128 + OrbitControls（沿用現有 CDN，不換框架、不引入建置工具）。
- GitHub Pages 靜態託管；`index.html` 仍由 `python3 build_portal.py` 產生。
- 字體：Zen Maru Gothic / M PLUS Rounded 1c；配色沿用 AGENTS.md（抹茶綠 `#799863`、聖誕紅 `#DC2626`、檜木棕 `#7C2D12`、錦江灣藍 `#0284C7`）。
- RWD：手機直式到桌機寬螢幕皆可操作。
- 不可 `git push --force`；**使用者核可預覽前不推送 `main`**（推送即上線）。

## 4. 方案比較（使用者已選 A）

| 方案 | 作法 | 取捨 |
|---|---|---|
| **A（採用）** | 程式生成 low-poly 模型；3D 拆成 `portal/*.js`；海岸線用公開地理資料轉 JSON；另做 `preview.html` | 細緻度偏積木感（正好符合 heart-island 風格）；文字回饋→修改速度最快 |
| B | Blender 建模匯出 glTF | 更精緻，但文字來回修改慢、檔案大、手機載入慢 |
| C | 全部塞在 `build_portal.py` f-string | 符合舊規範，但程式量數倍、`{{ }}` 易錯、難維護 |

## 5. 使用者已決定的內容

### 5.1 地形
- 南九州真實輪廓，北至熊本 / 阿蘇 / 黑川，南至薩摩、大隅半島。
- 錦江灣切入陸地，櫻島為灣內火山島。
- 北側切口做成浮空島岩壁斷面（提案，使用者未反對）。
- 阿蘇、霧島、櫻島有高度起伏；平原低平。

### 5.2 景點（實際位置）
熊本機場、熊本城、水前寺、阿蘇火山口 / 草千里、大觀峰、黑川溫泉、上色見熊野座神社、高千穗峽、宮崎（Seagaia 海景）、青島神社 / 鬼之洗衣板、日南摩艾像、鵜戶神宮、鹿兒島天文館、仙巖園、櫻島（含渡輪）、霧島神宮、人吉。

### 5.3 自駕路線
熊本 → 阿蘇 → 黑川 → 高千穗 → 宮崎 → 日南 → 鹿兒島 →（渡輪）櫻島 → 鹿兒島 → 霧島 → 人吉 → 熊本。熊本市區另有路面電車軌道。

### 5.4 季節：12 月冬天
- 地表：低彩度枯草抹茶綠、檜木暖棕岩壁；山頂薄雪。
- 天空：冬季晴空淡藍 → 地平線暖杏色漸層，緩飄雲朵。
- 陽光：低角度暖色斜射、長陰影。
- 海：low-poly 波動海面、岸邊白浪。
- 動態：櫻島冒灰煙、溫泉蒸氣、天文館聖誕燈飾閃爍、可關閉的小雪。

### 5.5 角色
| 角色 | 外型 | 專屬動作 |
|---|---|---|
| 阿純 | 可愛妹子、Q 版大頭、黃色毛帽（毛球）、及肩髮、暖色羽絨外套＋圍巾 | 蹦跳走路、手機自拍、看到景點雀躍揮手 |
| 阿嚕 | 一隻熊：圓滾棕熊、圓耳、紅臉頰、圍巾（**不仿熊本熊**） | 搖擺走路、摸肚子、偶爾跌坐或抱樹 |
| 阿姨 | 和藹婦人、短捲髮、暖色大衣、提購物袋，喜歡美食 | 在店家 / 小吃攤停下吃糰子或可樂餅、頭上冒愛心 |
| 姨丈 | 戴墨鏡的專業司機、夾克、轉車鑰匙 | 駕駛小巴（握方向盤）、下車伸懶腰、比讚、看地圖 |

- 共通：手腳交替擺動、上下起伏、眨眼、待機張望；點擊跳起＋對話泡泡；「全員歡呼」一起跳。
- 到景點時四人下車散步一段再上車。
- 台詞依所在景點變化。

### 5.6 預覽與回饋流程
- `preview.html`：每個項目有編號（角色 C1–C4、景點 L01…、物件 P01…、完整場景 S），可單獨旋轉檢視。
- 使用者以文字回饋（例：「C3 帽子大一點」），由 agent 修改；重新整理即可看到。
- 本地預覽：`python3 -m http.server 8000`。
- 使用者明確核可後才 commit + push 到 `main`。

## 6. 架構

```text
kyushu-travel-2026/
├── build_portal.py          # 產生 index.html；3D 區改為 <script src="portal/...">
├── index.html               # 產出
├── preview.html             # 新增：預覽畫廊（由 build_portal.py 一併產生；僅本地，.gitignore）
└── portal/
    ├── data/kyushu_coast.json   # 簡化後的海岸線（經緯度→場景座標）
    ├── data/route.json          # 景點座標、路線節點、各景點台詞
    ├── env.js        # 天空、海、太陽、雲、雪、光影
    ├── terrain.js    # 陸塊擠出、高度起伏、山頂積雪、岩壁斷面、道路
    ├── landmarks.js  # 各景點 low-poly 模型
    ├── characters.js # 四位角色模型與動作狀態機
    ├── props.js      # 路人、店家、市電、貓狗、渡輪、樹、燈飾
    ├── island.js     # 組裝場景、動畫迴圈、互動、對話泡泡
    └── preview.js    # 預覽頁的單項檢視邏輯
```

- 所有模組掛在單一全域命名空間（例：`window.KyushuIsland`），用一般 `<script>` 依序載入，不需打包工具，也可直接在 GitHub Pages 運作。
- 海岸線：用公開資料（Natural Earth 1:10m 或國土地理院）擷取南九州範圍，Douglas-Peucker 簡化到約 150–300 個點，用一次性腳本產出 JSON 並 commit（執行時不連外取資料）。
- 效能：重複物件用 `InstancedMesh` 或共用 geometry / material；只有單一方向光投影；shadow map 1024–2048；`devicePixelRatio` 上限 2；手機減少路人數量與雪花粒子。

### 6.1 建置、混淆與發佈流程（使用者已決定）

- **開發 / 預覽模式**：`portal/*.js` 維持獨立檔案，`index.html` 與 `preview.html` 以 `<script src>` 載入；不混淆、不注入防護盾（可正常使用 DevTools 除錯）。
- **發佈模式**：`build_portal.py` 將 `portal/*.js` 與 `portal/data/*.json` **內嵌回 `index.html`**，再執行 `obfuscate_and_protect.py` 混淆並注入防右鍵 / DevTools 防護（建議以 `python3 build_portal.py --release` 之類旗標區分，細節交實作者）。
- `portal/` 原始碼目錄是否要從 GitHub Pages 公開存取中排除：因 Pages 會公開 repo 內所有檔案，發佈版不依賴外部 `portal/*.js`；原始碼仍會在公開 repo 中可見（現況亦同，混淆僅保護線上頁面）。
- **驗收在兩個版本都跑**：混淆前與混淆後的 `index.html` 都必須無 JS 錯誤。
- **`preview.html` 只在本地使用**：加入 `.gitignore`，不 commit、不上 Pages、不混淆。
